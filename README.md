# חיפוש הטבות חבר

[פתיחת האתר](https://oronp.github.io/hever-search/)

אינדקס עצמאי בעברית. החיפוש מתבצע בדפדפן לפי שם עסק, תיאור, קטגוריה או עיר. כל תוצאה מקשרת לעמוד ההטבה המקורי.

## עדכון האתר

GitHub Actions מנסה לעדכן את האינדקס ביום ראשון ב־04:17 לפי שעון ישראל. אפשר להפעיל עדכון גם דרך **Actions → Refresh and publish → Run workflow**. פרסום האתר מתבצע אחרי איסוף מוצלח. בכשל איסוף האתר האחרון שפורסם ממשיך להיות מוגש.

אם GitHub Actions לא מצליח להתחבר לאתר חבר, אפשר להריץ `python refresh.py` מקומית ולדחוף את `stores.json` המעודכן לענף `main`. הדחיפה מפרסמת את הקטלוג שנאסף מקומית.

כדי לפרסם שינוי בממשק עם הקטלוג השמור, הפעילו את העדכון הידני עם `publish_snapshot`.

האפשרות `publish_pilot` מיועדת לפרסום ידני של מדגם „עיצוב הבית” ובו 42 עסקים. יש להשאיר אותה כבויה בעדכון מלא. אפשר לראות את היקף הרשימה ואת מועד האיסוף באתר.

## הרצה מקומית

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install 'beautifulsoup4==4.13.4'
python refresh.py --category לבית --subcategory 'עיצוב הבית'
python -m http.server 8000
```

הפקודה `python refresh.py` מריצה איסוף מלא. אפשר להציג את המדגם מקומית באמצעות `cp pilot-stores.json stores.json` לפני הפעלת השרת. תנאי המימוש ואחוזי ההנחה העדכניים זמינים בעמוד ההטבה הרשמי.
